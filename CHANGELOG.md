# Changelog

## 0.1.10-beta

First public beta for Minecraft 1.21.1 (NeoForge and Fabric).

- Make, edit and remove recipes in-game with a GUI, for vanilla stations and any mod's machines
- Edit recipes in KubeJS scripts and datapacks
- Set item amounts on machine inputs, and add extra slots with +
- Checklist, bulk changes, item unification, tags, tooltips and recipe locks
- Undo for everything; recipes are saved as a plain datapack
- Works with JEI, EMI and REI

Beta: back up your world first.
